# Vigilance Bulletin 2026 · सतर्कता बुलेटिन 2026

The Vigilance Bulletin of the Vigilance Cell, AIIMS Bhopal, published for Vigilance Awareness Week 2026 on the theme "सत्यनिष्ठा से समृद्धि / Probity for Prosperity".

The bulletin explains preventive vigilance in plain language, answers frequently asked questions, lists do's and don'ts for employees, and describes how to raise a concern. It is available as a web page with separate English and Hindi editions, and as a four-page A4 PDF of each edition.
